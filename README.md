# Configuration Copilot: prototype

Clickable prototype for the Vertex Ops case study (HashedIn by Deloitte, Campus PM Hiring 2026).

It shows Vertex Ops' internal Configuration Copilot running on the golden data set:

- **Sales (MVP):** Requirement Clarification Agent: ambiguity flags, follow-up questions, customer sign-off pack
- **Sales (MVP):** rule-based configuration checks that block handoff on hard errors
- **UAT (MVP):** Diagnosis & Tuning Agent: evidence, sandbox-tested fixes, requirement conflicts sent back to the customer
- **Production (MVP):** rule-based safety net (H1, H3, H4), no AI on live customers
- **Production (V2 preview):** fit monitoring: real drift vs seasonal noise vs sustained growth
- **Audit trail** of every agent output and human decision

Single self-contained HTML file; no build step. All data is synthetic and every customer is fictional.
